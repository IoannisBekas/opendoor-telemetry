How this was built. Every figure comes from a free, public source — no paid data vendor, no terminal. The pipeline that produces it replaces Parcl Labs, CoreLogic, Attom and Bloomberg with SEC EDGAR, Redfin Data Center and Opendoor's own published sitemap.
FinancialsSEC EDGAR XBRL companyfacts API, CIK 1801169. Tags resolved through fallback chains because Opendoor's tag usage changed in 2021.
Facility detailRendered debt-footnote tables located via each filing's FilingSummary.xml. Report numbering shifts between filings, so they are matched by name.
Market dataRedfin Data Center public bulk TSV, filtered to the six Opendoor concentration metros plus a national baseline.
InventoryOpendoor's published sitemap and the structured data already embedded in each listing page, fetched at one request per second.
